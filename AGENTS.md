# Shoof

This repository contains Shoof's generic reporting source. Do not add real tenant configuration, identifiers, private reports, credentials or customer data. Demo files and test fixtures must be wholly fictional and visibly labelled. Use the injected read contract and caller-driven sync interface; no marketing network connector, credential loader or active scheduler is provided. The protected runtime uses a single local owner login; no provider calls, public signup or email delivery. Authentication POST routes require same-origin CSRF protections. Keep its reporting HTTP interface read-only; local imports require explicit external inputs and must preserve the last good report on rejection. Test authentication and persistence only with synthetic data in temporary external directories. Never bootstrap or reset a real account without explicit owner authorization.

Run npm test, npm run check, npm run build and npm run privacy for code changes. Run browser QA for UI changes when a local browser tool is available. Private runtime inputs must remain outside the repository. Builds always use fictional demo data and refuse private input environment variables. Do not invent software ownership or add a license without the owner's decision.
