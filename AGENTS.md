# Marketing reporting

This is a local reusable source candidate. External publication requires explicit approval. Do not add real tenant configuration, identifiers, private reports, credentials or customer data. Demo files and test fixtures must be wholly fictional and visibly labelled. Use the injected read contract; no network connector, credential loader, send/mutation path or scheduler is provided.

Run npm test, npm run check and npm run build for code changes. Run browser QA for UI changes when a local browser tool is available. Private runtime inputs must remain outside the repository. Builds always use fictional demo data and refuse private input environment variables. Do not invent software ownership or add a license without the owner's decision.
